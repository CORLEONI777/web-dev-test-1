# BooksHeaven — Part 1

Standalone React + TypeScript + Vite frontend. No Figma dependencies, no database, and no external backend.

## Run

```bash
npm install
npm run dev
```

Open the forwarded Vite port (5173 in Codespaces).

## Includes
- BooksHeaven editorial homepage
- Search UI with local mock books
- Book detail page
- Curated collections
- Genre browsing
- Discovery UI
- Responsive layout
- Admin panel UI and books dashboard
